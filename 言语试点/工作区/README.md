## 文件

- `annotations.json`：每篇的元数据和原文链接、每段原文的 md5、遮点题句位置（段号、起止字位置、标签、id）、判断题、遮词位置与辨析。
- `core_clusters.json`：人民日报必读篇目的主题分组。
- `words_progress.json`：遮词已完成和待做的文章 id。
- `restore.py`：按链接抓原文、核对、还原成构建脚本的输入。
- `scripts/`：构建脚本、网页模板、浏览器测试、抓取工具、遮词任务说明和流程脚本。
