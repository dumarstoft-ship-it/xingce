# 遮词句：任务说明

你要帮一位考生备考 2027 年度广东省考（笔试预计 2026 年 12 月上旬）的言语理解。

## 背景

考生的看法是"指月之指非月"。命题人出一道看起来很合理的题，很多人去做、去解释，为每个说法赋予千种解释，但那都是手指。一道题选什么，理论上取决于两方面：文章作者那群人的行文契约，和出题人的思想。

考生按往年广东卷、国考卷的取材，挑了 151 篇人民日报、南方日报文章（2025-12 至 2026-10）来读，练对作者的语感。但光读不够，还要和出题人的大脑拟合。所以他做了一个离线网页"盖句精读"：读文章时，文中一些地方像命题人挖空那样被遮住，考生先自己想，再看原文。
- "遮点题句"模式已经做好（遮的是片段阅读常删的点题句），不用你管。
- "遮词句"模式（选词填空式遮词、语句填空式遮句）原先是另一个 AI 做的。考生的评价是：没有做到像出题人这么"阴险"，在"阴险"的同时看起来又是有理可循的；有些时候出题人还会选一些莫名其妙的句子盖住，这一点那个 AI 也没做到。

上一轮先试点重做了 11 篇。考生看过后说："对的，就是这种哪种都可以选的感觉，出题人就是喜欢这样出，按这样出完剩下的。"试点成品在 `/home/user/xingce/言语试点/工作区/词句新版/试点/` 下的 M1.json 到 M4.json（文章原文不在里面，题目、选项和说明在），想看可以看，不必照搬。

## 你的任务

重做分给你的文章的"遮词句"。把自己当成广东卷的命题人：这些文章到了你手里，你会在哪里挖空出选词填空、语句填空，挖几个空，配什么选项。

命题人的口味从真题里来，不从规则里来。先读真题，自己去品（真题不附答案，空处标成＿＿＿＿）：
- 广东卷（主要参照）：`/tmp/claude-0/-home-user-xingce/c27c4f14-7f89-5a62-8e0a-9c6994ddaec0/scratchpad/moon/` 下的 GD2022 到 GD2026 五份 `_政治常识言语.txt`，看言语部分。
- 国考副省级卷（次要参照）：同目录下 GK2021 到 GK2026。
- 考生之前做的溯源：同目录下 `溯源_原文到真题的改写记录.txt`。2025、2026 年度广东卷和 2026 年度国考，命题人从哪篇原文截了哪段、删了什么、挖了哪个词，原文用词是什么，都在里面。这是看命题人怎么下手最直接的材料。

品出来的东西不用写成规则交给我，用在挖空上就行。

文章是 JSON：paras 是自然段，段号 = 下标 + 1；already_masked_in_thesis_mode 是"遮点题句"模式已经遮住的句子，供参考（两种模式分开显示，不会叠在一起）。

每处挖空做成一道题，配 A–D 四个选项：
- 选词填空：正确项就是原文用词，这是真题的做法。
- 语句填空：正确项就是原句（可以是一句或半句）。
- 干扰项按命题人的手法配：要"阴险"，但站得住，考生选错后看了说明能服气。
- 每题写一段说明 note，考生答完后看：原文为什么最好，陷阱在哪；你觉得有必要的话，也可以点一句命题人看中了这里什么。写给考生看，话说清楚，不绕。
- 挖几处、挖在哪、出什么题型、一题几个空，都由你判断。这些空是考生读文章时一路遇到的，不是一张卷子，但每一处都应该是你作为命题人真会考的地方。

## 题做完后会怎么检验

- 每题会交给两个没见过答案的考生 agent 独立作答。他们能看全文和选项，看不到答案和说明。
- 如果他们有理由地选了别的选项，这题会退回给你。原因是：放进广东卷会有争议的题，命题人不会那样配。
- 网页上考生是按顺序一题一题做的，做完一题才看到它的说明。所以说明和选项里，不能写出同一篇里排在后面的题挖掉的原文。

## 交回

一次回复的输出有 128000 token 的上限，超了会被中断、丢掉进度。所以请每做完一篇，就先把这一篇写进 `full/out/parts_<批号>/<文章id>.json`，全部做完再合并成输出文件。不要在一次回复里写出整批内容。

把结果写进分给你的那个输出文件，格式：
```
{"articles": [
  {"id": "文章id",
   "questions": [
     {"kind": "选词填空 或 语句填空",
      "p": 段号,
      "blanks": [{"s": "被挖掉的原文，逐字复制", "pre": "紧挨在它前面的 4–12 个字，逐字复制；在段首就写空串"}],
      "options": ["A项", "B项", "C项", "D项"],
      "answer": "A/B/C/D 中原文那一项",
      "note": "说明"}
   ],
   "comments": "对这篇的判断或疑问，可空"}
 ],
 "comments": "整体的判断、疑问、建议，可空"}
```
- 一题有多个空时，blanks 按文中先后排列。
- 每个选项把各空的词按顺序用一个半角空格连起来，如 "充斥 当之无愧"。
- 选项里不要写"A."这样的前缀。
- comments 只给我看，不会显示给考生。
