# 主旨理解铺开：独立作答记录

做法同试点：每批的题交给一个没见过答案的作答 agent，它只看到题干材料、问句和四个选项。选了别的选项、理由站得住的，或者把握低、说两项难分的，退回出题 agent 修改，改完再测。把握"中"但凭材料里的具体线索排除了干扰项的，保留：考生要的就是乍看都说得通、细读才能排除的题。

## 第 7 批起：加进争议题

考生 10-29 提出真题里有不少模棱两可的争议题，从第 7 批起出题人照真题出一些，标成争议题。作答者选了别的选项不再一律退回：命题人的判法站得住（像真题里命题人在两可时的判法，说明里老实讲清另一项为什么也说得通）就留下，站不住的才退回。
