# 盲出校准：主旨类片段阅读（2026 年度广东卷 6 道）

对照的是出题 agent 交回的题（每篇一道主选、一道备选）和 2026 年度广东卷第 21、23、24、26、27、29 题。编号对应：T1→26，T2→21，T3→27，T4→24，T5→29，T6→23。

## 结论

- **撞上 2 篇**：T2→21、T4→24
- **部分撞上 3 篇**：T1→26、T3→27、T6→23
- **没撞上 1 篇**：T5→29

主要差在三处：

1. **删哪句。** 27 题删反了：真题留总书记引语、删作者自己的解读，它删引语、留解读。29 题真题删掉总起句"息息相关"、拿它当答案，它没删，答案放在了尾句上。
2. **问法。** 主选和真题同类的只有 3 道（21、24、29）。26 的标题题、27 的意图题只出现在备选里；23 的"以下干事创业精神，最贴合上文要求的是"两版都没想到。
3. **干扰项。** 它的 36 个干扰项全部取自本文，23 题真题的三个干扰项都是文外口号。真题有两个干扰项是把因果说反（21A、29B），它一个都没有。

撞上的两篇里，T2 的干扰项证据要打折；T4 是唯一能判截取范围的一篇，也对上了。

## 怎么判的

- **五项**
  - 删改：删了哪句，还是整段照录。
  - 问法：主旨、意图、标题，还是别的。
  - 正确项：意思一致就算，不要求字面相同。
  - 干扰项：看来路（取自哪里）和手法（怎么设坑）。
  - 截取范围：只有 T4 还原到七成，只在 T4 判。其余五篇材料里逐字的基本只有出题那一段，没法判断。
- **打折。** 材料里零星的别段原文，多数是溯源为了解释真题干扰项才记下的。它用这些现成短语撞上干扰项，证据力要打折，下文标"打折"。
- **总评**
  - 撞上：主选的删改、问法、正确项都对上，干扰项多数同源。
  - 部分撞上：有关键项对上，也有关键项没对上。只在备选里对上的，也归这一档。
  - 没撞上：删改和正确项都没对上。

- **截取范围**：材料里逐字的只有第2段，没法判断。

### T3→27 意图题｜《离开人，文化建设就会失去最根本的意义》（人民日报·思想纵横）

| | 真题 27 | 主选 | 备选 |

- **删改**：
  - 真题留引语、删作者解读。考生只能从引语里的"润物细无声""运用各类文化形式""生动具体""形象地告诉"自己推出作者想强调方法，所以问"意在强调"，正确项也往上概括了一层，成了"注重文化传播的方式方法"。

- **正确项**：真题 C 和它的两版都落在"怎么化"（方法）上，没落在"化什么"（核心价值观）上。它的说明里写"坑在把第3段讲的'化什么'当成本段讲的'怎么化'"，这正是真题 C 和 D 的分界。
- **干扰项**：
  - 真题三个干扰项的来路（第1、2段，本段第二句的字面，引语和第3段的"社会主义核心价值观"），它在主选、备选里都用到了，只是没凑在同一道题里。
  - 主选那两项要打折：第1、2段和第3段在材料里只有梗概，里面的短语是溯源为解释干扰项才记下的。
  - 备选 D 不打折，第二句就在截取段里。手法略有不同：真题 B 只抓字面，说成"文化工作水平的重要性"；它把主体偷换成"文化工作者"。
  - 它两版都拿题干所在段落里删掉的句子做干扰项：主选 C 取段尾"力戒急躁""久久为功"，备选 C 取被删的引语。这六道真题里，题干所在段落删掉的句子没有一句进了干扰项。
- **截取范围**：第4段后半只有碎片，它在【……】处直接拼接，那里原文可能还有字，不扣分。
