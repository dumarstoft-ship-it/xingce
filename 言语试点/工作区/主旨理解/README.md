# 主旨理解

"盖句精读"网页原来的"遮点题句"模式（遮住每段点题句，让考生先自己概括）用下来效果不大，换成**主旨理解**：在命题人会拿来出片段阅读的那几段，像真题一样出主旨类的题。

- 读到出题的那几段，正文先不显示，换成题卡：截好的题干材料、问句、A–D 四个选项，像考场上一样只看题干作答。
- 答完显示对错和说明，题干换成原文对照：命题人删去的字划掉，改写或添上的字加下划线。
- 会露出答案的段落（比如开头的提要）可以先收起，做完那道题自动展开。
- "遮词句"模式不变。

## 进度（2026-10-28）

- 试点 11 篇（和遮词句试点是同一批文章），30 道题：主旨 11 道，意图 15 道，标题 4 道。
- 出题前，出题 agent 先读广东 2022–2026、国考 2021–2026 的真题，以及考生做的溯源记录（命题人从原文哪段截取、删了什么、选项从哪来），口味从真题里品，不写成规则。
- 每道题交给一个没见过答案的作答 agent，它只看到题干材料、问句和选项，跟考场一样。第一轮 30 题选中 29 题；选偏的一题退回修改，复测通过。记录见 `独立作答记录.md`。
- 盲出校准：把 2026 年度广东卷藏起来，只给出题 agent 这几道真题背后的原文（据溯源还原），看它出的题和真题撞不撞得上。见 `盲出校准_主旨.md`。
- 试点给考生看过、认可了。

## 铺开（2026-10-28 开始）

- 考生已经读完按主题排序里"政绩观⑤党性修养与公私之辨"之前的文章，铺开只做这一组及以后的：人民日报其余各组、南方日报、常识，共 136 篇，去掉试点做过的 9 篇，127 篇，分 22 批，见 `全量/批次.json`。
- 每批一个出题 agent，说明同试点（`任务说明_主旨理解.md`），每批做完交给一个没见过答案的作答 agent 检验，退回修改后存进 `全量/`。
- 网页换新版本时，接着上次读到的那篇往后，停在第一篇还没做完的主旨题。
- 发给考生的网页只放从头连续做完的批次，免得考生往下读时跳过还没出题的文章。第一版（v3-zz-r1）放到 Z02，共 21 篇 57 题（试点 30 题加铺开 27 题）。

## 目录

- `试点/Z_ZP1.json` 到 `Z_ZP4.json`：试点题目；`全量/Z_Z01.json` 起是铺开的各批，格式相同。仓库是公开的，不放文章原文：题干材料存成对原文第 from_p 到 to_p 段的删改记录 `edits`（`["-", 起, 止]` 删去这几个字，`["+", 位置, 文字]` 添上文字），建网页时用原文还原。
- `任务说明_主旨理解.md`、`作答说明_主旨.md`：交给出题 agent 和作答 agent 的说明。
- `scripts/`：
  - `check_zz.py`：检查段号、选项、答案，逐字比对题干和原文，列出删了什么、添了什么。
  - `zz_leak_scan.py`：查题卡以外露着的文字会不会送出答案，前一题的说明会不会剧透后一题（出题 agent 写的）。
  - `make_zz_sheet.py`、`zz_score.py`：出作答卷（只有题干、问句、选项），对答案。
  - `zz_pack.py`：把题干换成删改记录再存档，并核对能一字不差地还原。
  - `zz_post.sh`、`zz_build.sh`：铺开时每批交回后检查、扫描、出作答卷；用存档建网页并跑两套实测。路径按工作机写死。
- 网页的脚本和构建在 `../词句新版/scripts/`，构建时加 `--zz 试点/Z_*.json`。
