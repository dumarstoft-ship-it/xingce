# 选词填空加练（加难版）　答案与依据

## 第4篇　从“摸象”与“称象”中悟方法

> 这 7 道经过了 4 个 agent 盲做（2 个仔细做、2 个限时凭语感做）和 1 个 agent 替干扰项辩护。

**1. A**　原文用词：攥指成拳；齐抓共建　｜　4 个 agent 盲做：A、A、A、A（4/4 做对）

第一空：“变为”前后要对照，而且应当用同一套比喻。“单打独斗”和“攥指成拳”都是出拳搏击的说法。“三地”好比几根手指，攥成拳头就是形成合力，正好承接前文“打破‘各自为政’的壁垒”以及疏解功能、共建屏障、产业融合这些协同动作。“众志成城”指万众一心像城墙一样坚固，重在意志团结，多用于抗洪、抗疫、抵御强敌等防守情境，“城”的比喻接不上“单打独斗”。文段讲的也不是“众人之志”，而是三地把力量、资源整合起来，所以B排除。“抱团取暖”预设处境困难、自身弱小，靠相互依靠熬过寒冬，多用于小微企业、散户村民；京津冀协同发展是主动谋划的国家战略，文中没有困境语境，D不恰当。

第二空：“‘共’字当头”（呼应“共抓大保护”）之后，列出的保护生态、建立统一市场、转方式调结构，都要上中下游一起抓、一起建，横线处必须落在“共”字上。“齐抓共建”正合。“齐头并进”只表示几方同时向前、各走各的，例如“各类经营主体齐头并进”，没有“共同”的意思，接不住“‘共’字当头”，所以C、D排除。

**最容易上当的选项：** C最能骗过语感。“上中下游齐头并进”读起来非常顺，“齐抓共建”反而不如“齐抓共管”眼熟，凭语感的人容易嫌它别扭而改选“齐头并进”。只有回头看“‘共’字当头”才能识破。B的“众志成城”显得更有气势，也有吸引力。

**2. D**　原文用词：纲举目张；整齐划一　｜　4 个 agent 盲做：B、B、B、B（0/4 做对）

两组“不是……而是……”都是前后对照。

第一空：“面面俱到”不分主次，所以“平均用力”。与它对照的词要既抓主、又带次，才能落到“统筹兼顾”：统筹是举纲，兼顾是照顾到各个目。“纲举目张”就是提起总绳、网眼全部张开，指抓住主要环节、带动次要环节，“纲”“目”两头都有，和“统筹兼顾”严丝合缝。人民网就有“不意味着‘眉毛胡子一把抓’……做到纲举目张……三者一起抓”的用法。“提纲挈领”现汉释义为“把问题简明扼要地提示出来”，偏重表述上的简要，常见“提纲挈领地介绍/阐明”；它只有抓要领这一头，没有带动全局、兼顾各方那一头，所以A排除。“统揽全局”和“统筹”语义重合，叠床架屋，也体现不出与“面面俱到”相对的主次之分，所以C排除。

第二空：“各展其长”强调差异，与它对照的应当是抹平差异、要求一律的“整齐划一”。一律的部件堆在一起，就是“机械叠加”。“简单相加”和“机械叠加”几乎同义，“简单相加的机械叠加”语义重复，修饰语没有提供新信息，也和“各展其长”构不成“一律对差异”的对照，所以B排除。“各自为政”和“各展其长”都落在“各”字上，构不成对照；况且各自为政的各部分根本没有叠在一起，所以C排除。

**最容易上当的选项：** B最能骗过语感。“不是简单相加，而是……”是人民日报的高频套话，“简单相加”和“机械叠加”在语感上就是一对，加上第一空又是对的，很容易直接选B。A的“提纲挈领”和“纲举目张”同样是抓纲，也很有迷惑性。

**挑刺 agent 的意见（认为干扰项也说得通）：** 替B辩护：B第一空也是“纲举目张”，胜负只在第二空，而“简单相加”有很强的论证。（1）“不是简单相加……而是有机……”是人民日报评论的固定句式，“简单相加对有机协同”的对照比“整齐划一对有机协同”更直接。（2）人民日报本报评论员的原句“不是简单相加的物理过程，而是深刻相融的化学反应，既要各展优势……”，几乎就是B填入后的句子：“简单相加”带“的”修饰一个同义的比喻性中心语，后面紧跟“各展优势”。这说明“‘简单相加’的机械叠加……‘各展其长’”在真实语料里完全成立。（3）出题人说“简单相加的机械叠加”语义重复，但这个文段本身就是“引号成语加同义注释”的模式：“‘面面俱到’的平均用力”中，面面俱到和平均用力本来就近义。所以“修饰语和中心语近义”不能当作排除理由。（4）“整齐划一”是“要求一律”，“机械叠加”是“堆在一起”，两者的因果要靠出题人补一句“一律的部件堆在一起”才接得上，反而不如“简单相加≈机械叠加”顺。

答案仍占优的地方：第一组引号词“面面俱到”与“纲举目张”是对照，按平行结构，第二组引号词应与“各展其长”对照，“整齐划一”与“各展其长”正好形成“一律对差异”的反义；而且有“一体化不是整齐划一，而是各有侧重、开放协同”这样几乎同构的真实用例。但B在语感和语料上都说得通，考生选B很难判错，属于可争议。顺带一提：出题人说“提纲挈领”只偏重表述，这一说法不准确，人民网有“提纲挈领抓住‘牛鼻子’”的工作方法用法。不过它和“弹钢琴（统筹兼顾）”是对举关系，正好说明它不能等同于统筹兼顾，A仍然排除。

**3. C**　原文用词：眼力；一村一策　｜　4 个 agent 盲做：C、C、C、C（4/4 做对）

第一空：“锁定……牛鼻子、突破口、着力点”是辨认、瞄准目标，靠的是看得准，也就是“眼力”，正对应“精准思维”。“魄力”是敢于决断的胆识（如“改革的魄力”），解决的是敢不敢干，不是看不看得准，所以A排除。“定力”是不受干扰、保持方向的稳定性（如“战略定力”），也不是辨认目标的能力，所以D排除。

第二空：“拒绝‘一刀切’”说的是工作方法，不搞统一政策，横线处的词要和“一刀切”针锋相对，又能受“精准”修饰，只有“一村一策”（因村施策）合适。人民网常见“‘一村一策’精准设计”“一村一策、精准施策”。“一村一品”是“一乡一业、一村一品”这一产业布局概念，指每村主打一个特色产品，回答的是种什么，不是怎么施策，反而可能被一刀切地推行。况且文中例子每村都是两业并举（特色种养与乡村旅游、生态康养与林下经济、渔文化体验与海洋产业），并非“一品”，所以B排除。“千村千面”描述的是结果（面貌各异），和后文“各美其美”重复，“千村千面的精准”也搭配不当，所以D排除。

**最容易上当的选项：** B最能骗过语感。“一村一品”是家喻户晓的乡村产业口号（人民网7700多条，约是“一村一策”的5倍），又紧跟“特色种养”“海洋产业”等产业例子，凭语感很容易选它。识破它要同时抓住两点：“一刀切”对的是“策”，例子里也不是“一品”。

**4. B**　原文用词：技术；空转　｜　4 个 agent 盲做：A、A、A、A（0/4 做对）

两个“比如”分别是两空的例证，横线处必须概括例子。

第一空：例子是热衷智慧治理、忽视软性治理手段，结果“看得见技术，管不住人心”。精准离开系统，就窄化为对技术手段的单一依赖，所以是“技术的陷阱”。“碎片化”指整体被拆成许多互不相连的碎块，可例子里没有“碎”，只有“偏”（偏重技术一头），也照应不上“看得见技术”，所以A、D排除。

第二空：例子是整体规划有了，却缺任务清单、责任主体、成效评估这些实施要素，结果“规划丰满，落实骨感”。规划和系统在转，却带不动落实，正是“空转”（人民网常见“政策空转、执行梗阻”“避免政策空转……确保落地”）。“失焦”指目标、焦点模糊或偏移，人民网用例是“做不到‘管得准’，治理可能失焦”“多目标并行引发的治理失焦”，问题出在瞄准上。例子中的整体规划方向清楚，并不失焦，缺的是实施环节，所以C排除。“空泛”指内容空洞，与“规划丰满”直接矛盾，所以D排除。

**最容易上当的选项：** C最能骗过语感。“离开精准”对“失焦”，看上去是天然的反义照应，而且人民日报确有“做不到管得准，治理可能失焦”的说法。只有对着例子看，才会发现问题不在瞄不准，而在落不了地。A的“碎片化”也利用了“脱离系统就碎片化”的条件反射。

**挑刺 agent 的意见（辩护不成立，答案唯一）：** 替A辩护：A第二空也是“空转”，胜负只在第一空。“脱离系统谈精准”，最直接的逻辑后果是失去整体，也就是“碎片化”：系统的反面就是碎片，这是人民网的标准对立。例子中只抓智慧治理这一个点，把社区调解、群众参与等手段割裂在外，治理工具各自为战、没有整合，同样可以说成碎片化。人民网有“单点化”导致“碎片化困境”、缺乏“整体规划”导致“陷入碎片化”的用例。何况“技术的陷阱”本身措辞少见，“技术”也不是“脱离系统”的直接后果，需要借例子才能落地。

辩护不成立的理由：（1）两个“比如”分别给两空作注。第二例的“规划丰满，落实骨感”对应“空转”，人民网也有“责任归属模糊，致使整改陷入空转”这样与“忽略责任主体”对得上的用例；照此平行，第一例的落点“看得见技术，管不住人心”就应当对应“技术”。（2）例子的病症是“偏”，偏重技术一头，不是“碎”，即整体拆成许多互不相连的碎块；“碎片化”描述的是多块割裂，不是对单一手段的依赖。（3）“碎片化陷阱”“碎片化的陷阱”在人民网零命中。A是很好的高难干扰项，但答案唯一。C项“失焦”也针对“精准”的反面，但和“落实骨感”对不上，弱于A。

**5. B**　原文用词：并行不悖；导航　｜　4 个 agent 盲做：B、B、B、B（4/4 做对）

第一空：“不能把二者对立起来、割裂开来”是从反面申说前两个词。“一体两面”针对“割裂”，横线处针对“对立”，要表达二者可以同时进行、互不冲突，所以填“并行不悖”。“相反相成”的前提是双方性质相反（常与“对立统一”连用），用它等于先承认二者对立，和紧接着的“不能把二者对立起来”自相矛盾，所以A排除。“齐头并进”用于多项工作、事业同时推进，不用于描述两种思维方法的关系，“并进”还暗含两条线各自前行，和“一体”相悖，所以D排除。

第二空：句末“既‘把方向’，更‘抓要害’”和前两分句逐一对应：系统观念对应“把方向”，精准举措赋能对应“抓要害”。能把方向的是“导航”（指引航向）。“护航”是护卫、保障（保驾护航），并不决定方向，所以C排除。“铺路”是创造条件，也与方向无关，所以D排除。

**最容易上当的选项：** A最能骗过语感。“一体两面、相反相成”听起来比“并行不悖”更有辩证色彩、更“雅”，第二空又是对的，凭语感极易选A。只有把“相反”和下一句“不能对立起来”对照，才会发现自相矛盾。C的“护航”靠的是“保驾护航”的高频语感。

**挑刺 agent 的意见（认为干扰项也说得通）：** 替A辩护：A第二空也是“导航”，胜负只在第一空，而“相反相成”有实打实的论据。（1）全文就是把二者当作方向相反、彼此成全的一对来写：望远镜对显微镜、登高望远对俯身细作、把方向对抓要害、“致广大而尽精微”（广大对精微）。这正是“相反相成”的典型义：看似相反，实则相成。（2）学习时报（人民网理论频道转载）在讲工作方法的文章里，屡次用“一对相反相成、充满辩证法精神的方法论概念”来概括“有所为与有所不为”“等不得与急不得”，用法和本题完全同类。（3）出题人说“相反相成”先承认对立，与“不能把二者对立起来”自相矛盾，这在中文理论文体里不成立。“对立统一”“辩证统一”之后接“不能对立起来、割裂开来”是标准句式；“相反相成”恰恰否定二者互斥，与“不能对立起来”同向，并不矛盾。“一体两面”本身就是“两个相反的面”。（4）出题人排除D时说，“并进暗含两条线各自前行，和‘一体’相悖”；这个逻辑同样适用于“并行不悖”中的“并行”。而且后句“为……导航”“为……赋能”是互相成全的关系，“相成”比只说“互不冲突”的“并行不悖”更贴切。

答案的依据：“并行不悖”正面回应“不能对立起来”（互不冲突），也是原文用词；“相反相成”在人民网总共只有38条，偏文史哲语体。所以答案不算错，但A完全说得通，甚至有人会认为A更好，属于可争议。C项“护航”不对应“把方向”，弱于A。

**6. C**　原文用词：登高望远；大势　｜　4 个 agent 盲做：C、C、C、C（4/4 做对）

第一空：横线和“俯身细作”对举，登高对俯身，望远对细作，“望远”又引出“看清大局、把握方向”，所以填“登高望远”。“居高临下”字面也是站在高处，但“临下”是往下看，不是往远看；人民日报用它多指高高在上的姿态，并且恰恰把它当作“俯下身子”的反面（“思政从来不是居高临下的宣讲，而是俯下身子的同行”“不曾居高临下地‘指导’乡村，而是俯下身子”）。它不能和“俯身细作”并列为两种推荐的方法，所以A排除。“高屋建瓴”是从高屋顶上往下倒瓶中的水，比喻不可阻挡的形势，重在“势”不在“看”，多用来评价讲话、论述（“一席话高屋建瓴”“高屋建瓴地指明”），和“俯身”也构不成对举，所以D排除。

第二空：“从工业文明走向生态文明”是有方向的历史进程，对应前文“把握方向”，所以是“时代大势”（“把握时代大势”是常见搭配）。“时代主题”是一个时代的中心课题，如“和平与发展”，是静态的题目，不是“从……走向……”的走势，所以B排除。“使命”是要承担的任务，搭配“担当/肩负”，不搭“把握”；“人类社会从……走向……”又是客观进程，不是任务，所以D排除。

**最容易上当的选项：** A最能骗过语感。“居高”对“俯身”在字面上对得最工整，第二空又是对的，凭字面对仗很容易选A。要识破，得知道“居高临下”在人民日报里是和“俯下身子”对立的贬义姿态。B的“时代主题”是高频政治词，也有吸引力。

**7. A**　原文用词：生态保护；局部先行　｜　4 个 agent 盲做：A、A、A、A（4/4 做对）

三组“平衡/统筹/兼顾+A与B”是平行结构。第三组“短期增长与长期发展”是相互牵制的两端；前面说“面临……挑战”，后面说“都考验治理智慧”，再往后要求系统观念（看大局）和精准思维（抓切口）并用。所以前两组也必须是此消彼长、需要权衡的两端，而不是同向并列的两项。

A：“产业升级与生态保护”是发展与保护的经典难题（人民日报“如何平衡发展与保护，是……重要挑战”）；“区域协调与局部先行”是整体均衡与部分率先的张力，正对应后文的系统与精准。两空都成立。

B：“产业升级”与“绿色转型”同向，常被并列为同一组举措（“通过科技创新、产业升级和绿色转型实现……”），谈不上“平衡”；“区域协调与城乡融合”也是并提的两项同向战略。B排除。

C：科技创新本身驱动产业升级，“整体推进”与“区域协调”同向，都没有张力。C排除。

D：“均衡发展”与“区域协调”意思基本重合，统筹二者等于统筹同一件事。D排除。

**最容易上当的选项：** B最能骗过语感。“产业升级和绿色转型”“区域协调发展和城乡融合发展”都是人民日报高频并提的固定组合，后者甚至有“统筹区域协调发展和城乡融合发展”的原句，读起来比“局部先行”顺得多。识破它要靠平行结构里“短期增长与长期发展”的张力关系和“平衡”一词。

## 第5篇　善治之道，在“未病先防”

> 这 7 道刚出完就停了，**还没经过盲做和挑刺检查**，答案是出题 agent 给的原文用词，我核对过原文。

**8. C**　原文用词：固本培元；消解

本题由第一空定答案，第二空四个词与“土壤”都能搭配，只起迷惑作用。

第一空：首句“治未病关键在‘防’”规定了后面的中医做法必须是在“未病”阶段预防；“减少病症发作”说的也是少生病，不是把病治好。后句用“则”对举，“靠前服务”“消解矛盾产生的土壤”都是矛盾还没出现时的事。“固本培元”是巩固根本、培补元气，平时把体质养好，病就不容易发作，三处都对得上。人民网“既要在重病时以猛药去疴，更要于日常固本培元”也把它放在“日常”一端，和“治病”相对。

A“辨证施治”是辨析已经表现出来的证候，再对证用药，前提是已经病了。《中国中医药报》局长署名文章把“辨证施治、对症下药”对应“查改纠偏”，并说要“治‘已病’与防‘未病’相贯通”，说明它属于治已病，与“治未病关键在防”相悖。D“标本兼治”是同时治病的表象和病根，同样以疾病已经存在为前提。B“正本清源”出自《汉书》，指从根本上整顿、清理，前提是“本”已不正、“源”已不清，属于纠偏补救；它也不是中医的讲究（人民网“中医讲究正本清源”零结果），“清源”只是字面上和“土壤”相呼应。

第二空（不作决定依据）：原文的“消解”更贴语境。“靠前服务”是柔性的、日常的做法，“消解”指逐渐消除、瓦解，和前句的“减少”程度相当。“铲除”“根除”斗争色彩重，多用于腐败、黑恶，放在服务群众、化解人民内部矛盾的语境里偏重。

**最容易上当的选项：** A最能骗过语感。“中医讲究辨证施治”是人民网上的现成说法（9条，“辨证论治”24条），听上去最“中医”；“铲除……土壤”又是“铲除腐败滋生的土壤”这个高频格式（1139条），两空都很顺口。辨证施治确实也能用来减少复发（人民网有“中药辨证施治减少肿瘤的复发转移”），所以只看“减少病症发作”排除不了它。必须抓住首句的“未病”“防”和后句的“靠前”才能排除。B的“清源—土壤”字面呼应是第二个陷阱。

**9. D**　原文用词：有迹可循；见微知著

第一空和“疾病发作前常有异常信号”对举，要表达“问题出现之前也有迹象可以追踪”。“有迹可循”正合。“早有端倪”（端倪即迹象）意思也通，所以B不能靠第一空排除。“有章可循”的“章”是章程、规章，意为有规矩可以遵照，和“信号”无关，A排除。“有据可查”指有凭据、记录可供查证，多用于台账、档案，C排除。

第二空决定答案，看三处照应：（1）段首“立足‘防’，就要善‘察’”说明本段的话题已从“防”转到“察”（发现）；（2）“因此”承接“有迹可循”，既然问题有征兆，结论应是从细小征兆推知将来的大问题；（3）后面的“精准捕捉苗头”是察觉的动作。“见微知著”（看到细微的苗头就能知道它的发展方向）三处都对得上。

“防微杜渐”是在坏事刚冒头时就加以制止，重点在“防”“杜”，是处置而不是察觉。放在这里，一是偏离了本段“善察”的话题，二是“因此”推不出“制止”，三是先说“杜绝”再说“捕捉苗头”，次序也颠倒了。人民网理论文章“见微知著、防微杜渐，及时发现苗头性、倾向性问题”把两词并列，也说明二者分工不同，不能互换。

“未雨绸缪”是事先做准备，仍然是“防”，不是“察”。“明察秋毫”只说目光锐利、看得细，多用于断案辨是非，没有“由微知著”的推断，又和“精准”语义重复；A已被第一空排除。

**最容易上当的选项：** B最具迷惑性。“早有端倪”本身没有毛病，B的第一空排除不了；“防微杜渐”既契合全文“防”的主题，又常和“苗头”同现（“抓早抓小、防微杜渐”“防微杜渐，及时发现苗头”），凭语感极易选它。要看到段首已经把话题换成“察”，“因此”推出的是察觉而不是制止。A的“有章可循”和“有迹可循”只差一个字，频次更高（2936条对969条），看得快的考生也容易上当。

**10. B**　原文用词：发酵；就地

第二空：后文“小事不出村，大事不出镇，矛盾不上交”讲的是在哪一层、在什么地方解决，也就是在发生地、在基层解决，不往上推，正对应“就地”。人民网“80%以上的苗头性、倾向性矛盾在镇村两级就地化解……‘小事不出村、大事不出镇、矛盾不上交’的治理目标正逐步变为现实”可以印证。

“源头化解”虽然高频，但“源头”属于问题出现之前“防”的阶段；这里讲的是“小病速愈”，病已经有了，“快速响应”也说明事情已经发生，D排除。“多元化解”着眼于渠道多样（调解、仲裁、诉讼等），和后文讲的层级、地点对不上；人民网“源头预防前置、中端多元化解、末端闭环管控”也说明“源头”“多元”是另外两个维度。“及时”和前面的“快速响应”意思重复，也照应不了后文。

第一空：前提是“搁置”，放着不管，时间一长，小矛盾逐渐酝酿、膨胀，“发酵”写出了这种随时间演变的过程，也和前一分句的“拖”、后文的“小事拖大”相呼应（人民网有“小隐患发酵成大问题”）。“积案”本身就是积压未结的案件，说“积压成积案”是同义反复，A排除。“蔓延”指向四周扩散，讲的是范围，而积案是时间上的累积，C排除。“激化”指矛盾变得尖锐，结果应是冲突、对抗，和“积案”也不对应；D已被第二空排除。

**最容易上当的选项：** D最具迷惑性。“矛盾激化”是最顺口的搭配，“源头化解”在人民网有2315条，又和本文反复出现的“源头”字眼呼应，凭语感很容易选。但“小病速愈”“快速响应”都说明问题已经发生，不再是“源头”阶段。C的“多元化解”频次更高（6982条），是第二个陷阱。A的“积压”和“积案”字面呼应，也有人会觉得顺。

**11. A**　原文用词：对簿公堂；联动

第一空：一场火情牵涉租客、房东和上下6户邻居，财产损失和赔偿责任交织在一起，所以说“复杂纠纷”。这类纠纷最常见的走向是打官司，“对簿公堂”正合，也和后文“却在街道……机制下快速解决”（没进法院，在基层就解决了）形成转折。

“不可开交”只能作补语，用在“闹得、吵得、忙得”之后，不能直接修饰名词（人民网“不可开交的”36条，全是“闹得不可开交的……”）；“演变成不可开交的复杂纠纷”缺了“闹得”，D排除。“积重难返”指长期积累的弊病、积习难以扭转，前提是要积很长时间，人民网多用于“积重难返的现象”“积重难返的债务”。一起刚发生的火情纠纷谈不上“积重”，和“极易”在时间上也矛盾，C排除。“剑拔弩张”形容双方对立、气氛紧张，人民网有“一场剑拔弩张的纠纷”，这一空排除不了B。

第二空决定B的去留：“一窗受理、一站处置”是一个窗口统一受理、多个部门联合处置，突出部门之间的联合行动，所以是“联动机制”。“兜底”指承担最后一道保障责任，“兜底机制”用于应急保障、困难群体托底、保底收购等，和前端的受理、处置无关，也和“快速解决”不搭，B排除。“协同”“闭环”本身能用，但所在的D、C已被第一空排除。

**最容易上当的选项：** B最具迷惑性。“剑拔弩张”把邻里因火情起冲突的紧张写得最有画面感，“剑拔弩张的纠纷”在人民网确有用例，凭语感会觉得它比平实的“对簿公堂”更好；“兜底机制”又是常见的政务词。要想清楚“兜底”是最后一道保障、不是受理处置机制，才能排除。D的“不可开交”也是和“纠纷”联想很紧的成语。

**12. D**　原文用词：侥幸；逃避；短视

三空都是“……的＋心态词”，所填词必须准确概括前面的引语或短语。

第一空：“万一没事”是明知有风险，却赌它碰巧不发生，正是“侥幸”。“麻痹”“大意”是放松警惕、疏忽，根本没意识到风险；说“万一没事”的人已经想到了风险，只是心存侥幸，所以二者不准确，A、C排除。人民网常说“侥幸麻痹心理”，两词并举，也说明所指不同。另外“……的大意”容易读成“主要意思”，作名词也别扭。

第二空：“怕麻烦缠身”，怕被麻烦缠上，于是躲开不管，“逃避”贴切，也和句首“阻碍行动”对应。“畏难”大体也说得通。“推诿”是把责任推给别人，文中没有“推给谁”的意思。“敷衍”是表面应付、草草了事，本身仍是一种行动，和“阻碍行动”不合。

第三空：“只图眼下”就是只顾眼前、不顾长远，正是“短视”，又和首句“事后灭火→事前防火”要求的长远眼光相对。“浮躁”是急躁冒进、急于求成，而“图清净”是怕事、求安稳、不作为，方向恰好相反，B排除。“功利”讲追求名利实惠，“清净”谈不上利。“苟安”（苟且偷安）和“图清净”很贴近，但C已被第一、二空排除。

**最容易上当的选项：** B最具迷惑性：前两空都对得上（“侥幸”正确，“畏难”也说得通）。“只图眼下”又容易让人联想到“急功近利、浮躁”这对常见组合，人民网就有“急功近利、浮躁冒进的短视心态”，不少人会选B。要注意“清净”是怕事求安，和“躁”正相反。C的“苟安”和“图清净”贴得很紧，专盯第三空的人会被它吸走。

**13. A**　原文用词：抓手；赋予

第一空：“把……作为……建设的总____”，被“作为”的是“创新发展‘枫桥经验’”，是一项具体工作。“抓手”比喻开展工作的着力点、切入口，“总抓手”就是统领全局的工作载体。人民网有“把学习推广‘枫桥经验’作为加强社会治安综合治理的总抓手”，几乎同构。

“遵循”是遵照依循的准则，作“总遵循”的应当是思想、理论（“……重要思想……是新征程上加强党的政治建设的总遵循”），一项工作不能成为“遵循”。“基调”是工作的总方针、总调子（“稳中求进工作总基调”），也不是一项具体工作。“钥匙”比喻解决问题的关键，固定说法是“解决……问题的总钥匙”，不和“建设”搭配。

第二空：“____其新的时代内涵”是双宾语结构，“其”指“枫桥经验”，意思是把新的时代内涵给予它，只有“赋予”能带这样的双宾语（“赋予其新的时代内涵”人民网792条）。“注入”必须用“为……注入……”的格式（“为中拉关系不断注入新的时代内涵”）。说“注入其新的时代内涵”，“其”只能理解成“它的”，注入的对象就缺了，人民网零结果。“丰富”“拓展”作用于已有的内涵（如“丰富其时代内涵”），而“新的”内涵是从无到有给予的，“丰富/拓展其新的时代内涵”逻辑不通，检索也都是零结果。

**最容易上当的选项：** B最具迷惑性。“总遵循”听上去最庄重；“注入新的时代内涵”在人民网有315条，比“赋予”还顺口。但“遵循”的主体应是理论，“注入”离不开“为……”，套进“注入其……”就不成立。C的“丰富”也很顺，要注意后面有“新的”二字。

**14. C**　原文用词：亦同此理；注脚

第一空：前句是医家讲医术高下的话，后句说基层治理也适用这个道理，用“亦同此理”（也是同样的道理）最贴切。

“殊途同归”是经不同途径到达同一目的地，“异曲同工”是曲调不同而同样精彩、做法不同而效果一样好。二者都要求有两个以上的比较对象作主语（“一海一山，路径各异，殊途同归”“与……异曲同工”），这里主语只有“基层治理”一个。更关键的是，二者强调“目的相同”“效果同样好”，本句要说的却是医理和治理“道理相同”（都重在治未病），意思也不对，A、D排除。

“概莫能外”是全都不能例外，用来强调某条普遍规律没有例外（“古今中外概莫能外”）。前句只是医家的一种说法，作者是借医理作类比，不是宣布一条治理也必须服从的铁律；而且单个对象用“概莫能外”通常要加“也”（“教育领域也概莫能外”），这里没有。

第二空：“X是Y最生动的____”，X是“防范在先、发现在早、处置在小”三条做法，Y是“坚持和发展新时代‘枫桥经验’”这项实践。“注脚”指用来说明、印证某事的事例，Y可以是一项实践（“这正是金融创新服务赋能乡村振兴最生动的注脚”）。“名片”是代表某一主体对外形象的标志，主体是校园、城市、地区等实体（人民网“最生动的名片”仅8条，均如此），一项“坚持和发展”的实践谈不上有“名片”，B排除。“写照”“缩影”本身大体能用，但所在的A、D已被第一空排除。

**最容易上当的选项：** A、D最能骗过语感。“殊途同归”“异曲同工”都是比“亦同此理”更“雅”的类比成语，顺着“医理与治理相通”的思路很容易选。实际上它们需要两个比较对象，强调的又是结果，而不是道理相同。B的“概莫能外”显得庄重有力，“名片”又是熟词，也会吸引人，要同时看出“概莫能外”拔高成了铁律，“名片”用错了对象。
