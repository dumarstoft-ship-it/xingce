# 任务：独立解资料分析题，并写解析

这些是粉笔"国考模考大赛"的资料分析题，原卷只有题本，没有答案和解析。它们会印进考生的打印册，答案和解析放进电子版习题本，所以答案必须对。每篇材料会由两个人分别独立解，答案一致才采用；你不知道另一个人的答案，请完全独立地做。

## 输入
任务文件（路径见下）是一个 JSON 列表，每项是一篇材料：mat（编号）、material（材料截图，按顺序）、questions（5 道题的截图，按顺序；原题号已去掉，按 1–5 编号）。

## 每道题怎么做
1. 用 Read 打开材料的每张截图和这道题的截图，看清楚每个数据、单位、时间口径（当月/累计、同比/环比、年末/全年、万/亿）。图表读数不清时放大看（可以用 Python 裁剪放大截图，存到你的草稿目录）。
2. 先想清楚题目问的是什么、该用哪个公式，再计算。**所有计算都用 Python 做**（写进草稿目录里的脚本，保留下来），不要心算。选项接近时要精确算到能区分为止。
3. 综合分析题（"能够/不能从上述资料中推出""有几项"）要逐项判断，每项都写结论和依据。
4. 选出答案。如果你觉得题目有问题（数据矛盾、没有选项符合、两个选项都对、截图缺内容），照样给出你认为命题人想要的答案，但 confidence 标 low，并在 problem 里写清楚。

## 解析怎么写（会原样印给考生看）
- 粉笔风格：先一句点明题型（如"本题考查基期比重计算"），再写定位到的数据、用的公式、关键计算过程、和哪个选项最接近，最后"故正确答案为 X。"
- 数学式用 `$...$`（KaTeX），如 `$\frac{3155}{1+8.4\%}\approx 2910$`。普通数字和百分号直接写。
- 80–250 字；综合分析题可到 350 字。要有能指导速算的写法（如截位直除、特征数字、百分点与增长率的关系），点出常见陷阱。
- 不写"根据我的计算""程序算得"这类字眼。

## 输出
写一个 JSON 文件（路径见下）：
```json
[{"mat": "MK2710X-M2",
  "q": [{"n": 1, "answer": "C", "confidence": "high", "jiexi": "……故正确答案为C。", "problem": ""}, … 共 5 道]}]
```
写完后用 Python 检查：每篇 5 道、answer 都是 A–D、jiexi 都以"故正确答案为X。"结尾且 X 与 answer 一致。回复只写 "done <篇数>"，以及 confidence 为 low 的题号和原因。
