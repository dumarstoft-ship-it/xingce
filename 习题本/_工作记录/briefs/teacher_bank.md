# 任务：把一位名师的数量关系笔记整理成可用的题库

## 背景
考生在备考今年 12 月初的广东省考。考生上传了一位很厉害的老师（"忧郁牛牛"）的《26 数量关系笔记》，觉得他选的题非常犀利，希望习题本参考并收入这些题。考生的原话："数学这个东西就是降维打击的，难题除了知识难以外，还有一些手法的使用也是比较复杂的……平时训练的题至少得有意义，得卡住我，让我学到一点什么。"
笔记已经按例题切好，每道例题有一张截图：上面黑字是题目，彩色字和红框是老师的讲解和答案。

## 材料
- 例题清单：/tmp/claude-0/-home-user-xingce/88bc77ab-be1a-5cff-a4a7-35b764f8964e/scratchpad/teacher/examples.json。每条字段如下：
  - tid、section（笔记里的节名）；
  - question：程序提取的题目文字，可能有错字、缺公式；
  - solution：老师讲解的文字；
  - source：出处，如"2022国考"，没有则为空；
  - db_match：程序判断它和题库里哪道真题是同一道题，可能判错；
  - review_crop：截图路径。
- 题库分类标准：/tmp/claude-0/-home-user-xingce/88bc77ab-be1a-5cff-a4a7-35b764f8964e/scratchpad/taxonomy.md。模块代码：M01 和差倍比与比例，M02 不定方程与数字特性，M03 工程，M04 行程，M05 经济利润，M06 排列组合，M07 概率，M08 几何，M09 最值（抽屉与构造），M10 统筹优化与线性规划，M11 容斥，M12 溶液混合与平均数，M13 周期、日期与杂题，M14 数论与计算。
- 你负责的 tid 范围在任务里给出。每道题都要用 Read 看截图，以截图为准。

## 每道题要做的
1. 判断能不能作为一道练习题收入。
   - 纯概念演示、没有设问的，标 keep=false。
   - 题目残缺、无法还原的，也标 keep=false。
   - 与本批另一道题完全相同的，也标 keep=false。
2. 核对 db_match：确实是同一道题才保留，否则改成 null；如果你确信题库里有而程序没认出，可以写上编号。
3. 写出干净的文字版题干和四个选项。
   - 去掉水印字样，如"公众号樱有尽有"之类。
   - 不要把老师的批注写进题干。
   - 原题没有选项的，按真实的错误思路设计四个选项，并标 options_added=true。
4. 定答案，并用 Python 验算。
   - 截图里老师的红框或讲解可以作为参考，但要自己核实。
   - 能算的题都写验算脚本 verify/teacher_<tid>.py，从题面数据求解，最后 print 出正确选项字母，不能写死答案。
   - 老师的答案如果有误，以验算为准，并在 issues 里写明。
5. 按老师的思路整理解析（300 字以内）。
   - 保留他的关键手法和"降维"的那一步，把省略的步骤补齐。
   - 点出最典型的错误。
   - 不写"参考用时"。
6. 写 learn：一句话说清做这道题能学到什么（哪种手法、哪种转化或识别信号）。
7. 写 level：从一个认真备考的考生的角度，整体判断难度，取值为 基础、中等、难、很难，不用硬规则。
8. 图形：题目需要图的，能用简单 SVG 准确画出的就画出来（figure.type="svg"），不要画上任何答案信息；画不了的标 figure.type="crop_needed"，并说明需要什么图。

