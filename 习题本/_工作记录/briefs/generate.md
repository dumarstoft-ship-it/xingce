# 任务：按考法地图出改编题

先读 `briefs/common.md`，再读任务里给的考法地图 `blueprints/<模块>.md`（找到你负责那一天、那几组的配置），并用 Read 看你这几组的种子真题截图（`crops/real2/<id>_q.png`、`<id>_j.png`）。

## 出题要求
- 严格按考法地图里分给你的组和数量出题；每组的"巩固/深化/拓展"比例照地图来。
- **每道改编都要有明确的"变"**：问法变了、结构变了、多了一层转化、换了考法组合，或者是真题里没有的新变形。只换数字和情境的题不超过本批的 15%。
- 难度梯度：组内由浅入深；本批里要有若干道"考场上该放弃或必须用技巧才能 90 秒内做完"的题，并在解析里说明取舍。
- 情境多样，贴近广东卷：政务服务、基层治理、产业园区、大湾区交通、外贸展会、农业、文旅、社区活动等；但不要生硬。
- 选项设计：干扰项来自真实的错误路径（漏算一步、比例颠倒、忘了取整、只考虑一种情况……），解析里点出最典型的那个。四个选项数值要合理，不能一眼排除三项（除非这道题就是考"选项特征秒杀"，如尾数、奇偶、倍数，此时要在解析里点明）。
- 本批答案 A/B/C/D 分布大致均匀。

## 验算（硬性）
- 数学运算、综合推理、翻译推理、真假推理：每题写一个独立的 Python 脚本 `verify/<vid>.py`，从题面数据出发求解（综合推理/真假推理用穷举所有可能情况；翻译推理用真值表穷举），最后 `print` 出正确选项字母。脚本里不能直接写死答案。运行全部脚本，确认输出与你标的答案一致、且恰好一个选项成立（综合推理要验证"必然为真/可能为真/不可能"等设问在所有解下的真假）。
- 论证类逻辑（加强、削弱、前提、解释、结构相似、评价）无法程序验算：每题写完后，换一个角度自己"盲做"一遍，确认最优项唯一；在解析里逐项说明其余三项为何不选（简短）。

## 输出
写一个 JSON 文件（路径在任务里给出），内容是一个列表，每个元素：
```json
{
  "vid": "D01-M01-v07",
  "group": "考法二：……（与考法地图里的分组标题一致）",
  "seed": "2025GD-36 或 考法名",
  "direction": "巩固 | 深化 | 拓展",
  "kaofa": "≤20字",
  "technique": "≤12字",
  "difficulty": 2,
  "time_s": 75,
  "stem": "题干（可含 $...$）",
  "options": {"A": "...", "B": "...", "C": "...", "D": "..."},
  "answer": "C",
  "jiexi": "解析",
  "figure_svg": null,
  "verify": "verify/D01-M01-v07.py 或 null"
}
```
完成后用 python 检查 JSON 可读、条数正确、每题四个选项、答案在 ABCD 内、验算脚本全部运行通过。回复里简要汇报：完成条数、各组数量、答案分布、你觉得最有新意的 2–3 道题、任何疑虑。

## 一拖 n（共用材料）
综合推理和部分逻辑题可以出"一个材料、几道小题"。这时每道小题照常一条记录，但多加一个字段 `"shared_stem": "共用材料全文"`（同组各题完全相同），`stem` 里只写这道小题自己的设问（可含"如果……，则……"附加条件）。同组小题的 vid 要连续。

## 没有官方解析的真题
如果分给你的组里有"自解"真题（任务里会列出 id；它们没有官方答案和解析），请为每道写一段解析（风格同改编题），数学题用 Python 验算答案。写到单独的文件 `gen/real_<任务里给的前缀>.json`：`[{"id": "2026GD-41", "answer": "B", "jiexi": "……", "verify": "verify/real_2026GD-41.py"}]`。

## 题干里不要有任何提示（考生要求）
- 题目页上不显示考法、分组、出处，考生要自己识别题型。所以**题干和选项里绝不能出现提示考法或技巧的字眼**（如"利用赋值法""可用十字交叉""本题属于……"），也不要出现【改编】【真题】等标签。
- 情境和设问要像真题一样自然；考法只写在 kaofa/technique 字段和解析里。

## 审稿反馈带来的补充要求
- **不要沿用种子真题的原数据**：考生通常刚做完那道真题，同一组数据（哪怕已知和所求互换）会被直接记住，训练就落空了。每道改编都要换新的数据和情境。
- 同一组里不要出现两道数据相同、只是正推/逆推的题；一组内的题目要覆盖不同的模型或问法。
- 同一批题干的设问格式保持统一：数学题一般以"（ ）+单位"或"……是多少？"结尾，二选一后整批一致。
- 解析控制在 250 字以内；解析里不要写"参考用时"（排版时会按 time_s 自动加）。
