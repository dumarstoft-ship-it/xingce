# 任务：为一个模块画"考法地图"并规划各天的改编

你负责一个模块（任务里给出模块代码、名称、该模块在 42 天里占哪几天、每天有哪些真题）。先读 `briefs/common.md`。

## 你要交付的文件：`blueprints/<模块代码>.md`
内容包括：

1. **考法清单**：把这个模块拆成 8–15 个"考法"（子题型），每个考法写：
   - 名称、识别信号（题干里看到什么就知道是它）；
   - 最快解法（秒杀技巧/核心转化）和通法；
   - 常见陷阱、出题人常用的干扰项设计；
   - 题库里属于这个考法的真题 id；
   - 广东卷/国考/浙江卷近年的出现情况和趋势（据题库判断）。
   - 不要只总结题库里出现过的考法；这个模块在行测里**应有而题库里没有或很少**的考法也要列出来，标"题库缺"。这正是改编要补的。

2. **改编方向**（考生要求：更广、更深，不局限于原题）。每个考法给出具体的改编思路，至少覆盖三类：
   - **巩固**：同一考法换一个"问法"或"已知/所求互换"（正推变反推、求时间变求效率、求概率变求人数……），不是只换数字；
   - **深化**：多一步转化、两个考法嵌套、条件更隐蔽、需要分类讨论或取整、加入"最值/至少"等追问、数据设计成必须用技巧才能快做；
   - **拓展**：新情境新结构（政务、产业、大湾区、民生等广东常见情境）、跨模块组合（如工程+利润、行程+比例、排列组合+概率、几何+最值）、真题里少见但合理的变形。
   - 每个方向举 1–2 个"题面骨架"示例（不必是完整题）。

3. **各天配置**：这个模块的每一天（任务里给出天数），列出：
   - 当天放哪些真题（从给定名单里排顺序，按考法分组；难度大体前易后难，第 1 次出现的那天以基础到中等为主，最后一次以深化和拓展为主）；
   - 当天要出多少道改编（= 45 − 当天真题数；综合推理为 15 − 真题数），按考法和"巩固/深化/拓展"三类分配到具体数量，并写明每组改编以哪道真题或哪个考法为种子；
   - 当天的分组标题（排版时会作为小标题出现，如"考法一：给定时间型（赋值总量）"），题目按组排列，组内先真题后改编。

4. **真题核查**：浏览分到本模块的真题，如果发现某题其实属于别的模块、官方答案存疑、截图/文字残缺无法使用，列在文末"问题清单"里（写 id 和原因）。没有官方答案的真题（id 列表在任务里给出），请你**解出答案**，数学题用 Python 验算，并在"自解答案"表里写：id、答案、一句话思路。

## 不要做的事
- 不要在这一步写完整的改编题。
- 不要改动题库文件。
