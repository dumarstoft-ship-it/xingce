# 任务：盲审改编题

先读 `briefs/common.md`。你拿到两个文件：
- 题目文件（只有题干和选项，没有答案）：任务里给出路径；
- 答案文件（出题人的答案、解析、验算脚本路径）：**先不要打开**。

## 步骤
1. 只看题目文件，逐题独立作答。数学、综合推理、翻译/真假推理题自己写程序或认真推算；论证类题按考场标准选最优项。每题记下你的答案和一句话理由；如果你认为题目有歧义、条件不足、两个选项都对、没有正确选项、数据不合理，直接记为"有问题"并写原因。
2. 做完全部题后再打开答案文件，逐题对比：
   - 答案一致：再看解析是否正确、简洁、点到了最快方法；
   - 答案不一致：重新审视，判断是你错还是出题人错，写明结论；
   - 运行验算脚本（如有），确认它真的是从题面独立求解，没有写死答案。
3. 同时从整体看：是否有雷同题、是否只换数字、难度梯度是否合理、干扰项是否有迷惑性、语言是否像真题。

## 输出
写一个 JSON 文件（路径在任务里给出）：
```json
{"items": [{"vid": "...", "my_answer": "B", "key": "B", "verdict": "ok | fix | drop", "problem": "（verdict 不是 ok 时写清楚问题和建议改法）"}],
 "overall": "整体评价与建议（简短）"}
```
verdict 标准：ok = 可以直接用；fix = 小问题，按建议改即可（如解析笔误、某个干扰项太弱、措辞歧义）；drop = 答案错误或题目有硬伤，建议重出。
