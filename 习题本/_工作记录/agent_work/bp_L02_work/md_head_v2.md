## 二、通用工具箱（解析里反复点名）

### 2.1 真假推理五步法

1. **翻译**：把每句话写成符号（且、或、→、非、所有、有的），二值域要先统一成一个变量（如“线上”写成“非线下”），并把“某人说的不对”换成它的否定。
2. **找关系**：按顺序依次找矛盾、反对、下反对、推出关系，再看有没有说法不同、意思相同的两句（等价，见 2.2）。
3. **看其余**：用真假数量限定处理其余的句子（见 2.3）。
4. **回代**：把推出的情况代回所有句子，确认真话数符合限定；问“可能／一定／无法确定”时，要列出所有满足条件的情况。
5. **对设问**：问的是“一定为真”“一定为假”“可能为真”“无法确定”，还是“谁说真话”“几句为真”，最后一步别答错方向。

### 2.2 五种关系速查

| 关系 | 真假规律 | 常见形式（含隐性） |
|---|---|---|
| 矛盾 | 必一真一假 | A／非A；所有S是P／有的S不是P；所有S不是P／有的S是P；A且B／非A或非B（“至少一个没”“不会都”）；A或B／都不；如果A则B／A且非B；只有A才B／B且非A；除非A否则B／非A且非B；要么A要么B／要么都要么都不；至少n个／至多n−1个；恰n个／不是n个；单选域中“是X”／“是其余某几个之一”；二值域中“甲乙都线下”／“甲线下则乙线上”；“X说的是假话”／X的原话 |
| 反对 | 至少一假（可同假） | 所有S是P／所有S不是P；A且B／非A且非B；单选域中“是X”／“是Y”；分组多于两组时“在X组”／“在Y组”；“至少两个”／“只有一个”；“恰一个”／“恰两个”；“都没完成”／“甲完成了” |
| 下反对 | 至少一真（可同真） | 有的S是P／有的S不是P；A或B／非A或非B；“有的达标”／“A没达标”；“至少两个”／“至多两个” |
| 推出 | 前真后必真、后假前必假 | 所有⇒某个⇒有的；A且B⇒A⇒A或B；“是X”⇒“是X或Y”；“是X”⇒“不是Y”；“三件都获奖”⇒“某件获奖” |
| 等价（互推） | 必同真同假 | 如果A则B／如果非B则非A（逆否）；A或B／如果非A则B；除非A否则B／A或B；“只有B才A”／“如果A则B” |

### 2.3 真假数量限定×关系：直接出结论的组合

| 已知 | 能直接得到 |
|---|---|
| 有一对矛盾 | 这一对占一真一假，其余句子按“真话总数−1”处理（只有一真→其余全假；只有一假→其余全真；两真两假→其余一真一假） |
| 两对矛盾 | 两对共占两真两假；“只有两真”时其余全假，“三真”时其余恰一真 |
| 反对＋“只有一假／至多一假” | 假话就在这对反对中，其余全真 |
| 下反对＋“只有一真／至多一真” | 真话就在这对下反对中，其余全假 |
| 两组下反对共用一句＋“只有一真” | 唯一的真话只能是那句公共句，其余全假 |
| 两句等价 | 必同真同假：“只有一真”时这两句必假；“只有两真”时分“两句同真、其余全假”和“两句同假、其余恰两真”两种情况 |
| 矛盾＋反对＋“恰有两人说谎” | 两个说谎名额被占满，其余全真 |
| 只有推出关系 | 只有一真时，强句必假；只有一假时，弱句必真；两真两假时，看剩下那一对的强弱 |
| 什么关系都没有 | 选项是完整情况时，直接代入数真话；否则从肯定句或强句开始假设 |
| 身份型（诚实／说谎） | 先找“自指”句（如“我们中至少一人说谎”“我和他都说谎”），说谎者不能说出这类句子 |

### 2.4 归纳推理“三查一看”

- **查话题**：主体、对象、范围要与题干一致（如“调控心脏的神经”不能换成“调控内脏器官的神经”；“某类益生菌”不能换成“所有益生菌”）。
- **查程度**：可能／往往／大多／一定／所有／唯一／越…越，选项不能比题干说得更满。
- **查关系**：因果、条件（必要／充分）、并列、先后、相关，选项不能改掉题干的关系。“同时出现”“先后发生”“负相关”都不等于因果；“离不开”不等于“只要…就”。
- **看问法**：可以推出、不能推出、最能支持、最能概括、可能为真、不可能为真，答案的标准各不相同（见 2.6）。

### 2.5 归纳错误项十类（附题库例子）

| 陷阱 | 识别 | 题库例 |
|---|---|---|
| 无中生有 | 选项里的新概念、新比较、新原因在题干中找不到 | 2022SC2-80 B、C；2024SD-99 B、D；2025HB-108 A |
| 偷换主体／概念 | 调节者换了、对象范围换了 | 2024HB-108 A（肌苷↔肌苷转运蛋白）；2023HB-102 B（心脏↔内脏器官） |
| 扩大范围／绝对化 | 所有、任何、完全、唯一、一定 | 2025SD-98 C、D |
| 因果倒置／强加因果 | “因为…所以”“导致”“是…的原因” | 2020HB-108 B；2020SZS-75 B |
| 并列改因果 | 题干是“不仅…也”，选项变成“因为…所以” | 2020HB-103 C |
| 必要改充分 | “离不开”变成“只要…就” | 2020HB-103 A |
| 比较对象不当 | 部分与整体比，或比较题干没给的对象 | 2024SD-99 C |
| 时间错置／过度预测 | 把“此前”“将来”说成确定 | 2022HB-107 B、C；2024SD-99 B |
| 概念范围 | “唯一液态金属”只管金属 | 2023GK-110 C |
| 应用推断／数量偷换 | “可用于治疗”；人次≠人数、比重≠数量、平均≠个体 | 2024HB-108 D；2022ZJA-105 D |

**正确项的四种常见样子**：同义替换（2025SD-98 B）、对机制的概括（2022ZJA-105 B、2025HB-108 C）、措施有助于（2020HB-108 A）、信息串联（2022SD-74 D、2020SC1206-84 C）。正确项常带有“可能”“有助于”“某些”“之一”这类收着说的措辞。

### 2.6 设问对照

| 设问 | 正确项标准 |
|---|---|
| 可以推出／下列说法正确 | 由题干必然得出（日常结论题容许同义替换与合理概括） |
| 不能推出（选非） | 找出无依据或与题干冲突的那一项；其余三项都要能在原文找到依据 |
| 最能支持／最可能推出 | 被题干支持程度最高的一项，可以含有温和的趋势推断（2020SZS-75 C） |
| 最不能支持 | 题干完全没有涉及，或与题干相反的一项 |
| 最能概括 | 覆盖全部要点、不加码的一项 |
| 一定为真／一定为假 | 在所有满足条件的情况中都成立／都不成立 |
| 可能为真／不可能为真 | 至少在一种情况中成立／在任何情况中都不成立 |
| 无法确定 | 在某些情况下成立，在另一些情况下不成立 |

### 考法一：显性矛盾＋只有一真／一假（找矛盾、看其余）

- **识别信号**：三到五句话里，能直接看出一对互相否定的话（如“A街道评不上”与“会是A街道”，“都不建”与“至少建一个”）；限定是“只有一真”“只有一假”“有两项错误”。
- **最快解法**：找到矛盾就不再假设，矛盾对占掉一真一假，其余句子一次判完：只有一真→其余全假，取各句的否定；只有一假→其余全真，直接用。2025SD-94 中甲乙矛盾，丙为假，否定丙得“建教学楼”；2025HB-110 中小周、小郑矛盾，小王为假，得“小王是亚军”。
- **通法**：真值表或假设法，每次假设一句为真，算出其余句的真假并计数。
- **陷阱与干扰项**：条件句的否定写成“前假”（应为“前真后假”）；选言句的否定写成“至少一个不”（应为“都不”）；把没确定的量当成已知（2025SD-94 中 D“体育场和教学楼”）；问“谁说真话”时，矛盾对里谁真还要再判一步。
- **真题**：2025SD-94、2023ZJA-102、2025HB-110。
- **趋势**：山东、河北 2025 年仍在考，属于基础分，要做到 40 秒以内。第 14 天另设“名次情境＋补集矛盾”作为与考法二的过渡。

### 考法二：隐性矛盾（先翻译再找矛盾）

- **识别信号**：表面上没有“一正一反”，但出现条件句（如果、只有…才、除非）、“要么…要么”、数量词（至少两人、至多一人、恰两人）、二值域（每人要么线上要么线下）、单选域（只选一个）。
- **最快解法**：先翻译成统一的变量，再套 2.2 表中的隐性矛盾形式。2022GK-109 中“都获奖”与“至多1人获奖”矛盾；2023SC-85 中在“要么看电影要么购物”的二值域里，“甲乙都购物”与“甲购物则乙看电影”矛盾；同理，二值域里“甲、乙方式相同”与“甲、乙恰一人线上”也是矛盾（第 27 天改编）。
- **通法**：把每句写成符号，两两检查是否“一真一假”。
- **陷阱与干扰项**：把“只有A才B”翻成“A→B”（方向反了）；“除非A否则B”翻错；二值域不统一，导致“乙线上”和“乙线下”被当成两个独立变量；“要么都…要么都不”不会翻。
- **真题**：2022GK-109、2023SC-85（另外，2022ZJA-101、2024HB-102、2024SC-84 的矛盾也是隐性的，归在考法三）。
- **趋势**：国考 2022、四川 2023 都考过；它与翻译推理（广东每年 2 道）共用“关联词翻译”，是本模块迁移价值最高的考法。

### 考法三：矛盾＋多真多假（两真两假、几人说谎）

- **识别信号**：“两真两假”“三真一假”“有两人说谎”“三真三假”。
- **最快解法**：矛盾对先占掉一真一假，剩下的句子再判一次，通常是一对有推出关系的句子：“强句真⇒弱句真”，所以强句假、弱句真（2020SD-66 中“丁没捐”⇒“乙丁至少一家没捐”）。两组矛盾会占满两真两假，剩下的句子按余数处理。“矛盾＋反对”能把说谎名额夹满（5 人 2 谎时，矛盾对一谎、反对对至少一谎，剩下的人全说真话）。
- **通法**：对剩下的一对句子分两种情况假设。
- **陷阱与干扰项**：剩下一对的强弱方向判反；问“哪两人说对”时只算出情况不回头数；6 人 2 谎时漏看“某人说的是假话”也构成矛盾（2020SZS-71 中乙与丁）。
- **真题**：2020SD-66、2024HB-102、2022ZJA-101、2024SC-84、2020SZS-71。
- **趋势**：2022—2024 年浙江、河北、四川都是两真两假，是近年主流。改编在“三真一假、三真两假、6 句三真、7 句恰 3 真、真话比假话多”等限定上做变化。

### 考法四：反对与下反对（含至多、至少限定）

- **识别信号**：没有矛盾，但有一对话“不能同真”（冠军是欧洲国家／冠军是南美国家；都达标／都没达标；至少两个／只有一个）或“不能同假”（有的能／有的不能；甲或乙去／甲乙至少一人不去）；常配“只有一假”“至多一假”“只有一真”。
- **最快解法**：反对配“只有一假／至多一假”时，假话就在这一对里，其余全真（2023SD-66、2021SD-66）；下反对配“只有一真”时，真话就在这一对里，其余全假（2022SD-75）。
- **通法**：假设法。
- **陷阱与干扰项**：把反对当成矛盾，以为“一真一假”（反对可以同假）；“至多一假”读成“至少一假”；推出“甲能”以后没回头判下反对的两句（2022SD-75 的结论是“都不能”，改编会故意反过来考“都能／都完成”）。
- **真题**：2023SD-66、2022SD-75、2021SD-66（小夏的话与小张、小王的话各成反对，“至多一人说假话”只能是小夏；官方答案B，已补齐）。
- **趋势**：山东连续三年都考（2021、2022、2023），是“无矛盾时的第一抓手”。改编补了单选域的“是X／是Y”、数量型反对、选言形式的下反对、“至多一句为真”、两组下反对共用一句，以及反对与下反对叠加的题。

### 考法五：推出关系与代入（无矛盾时怎么破）——广东考法

- **识别信号**：几句话之间既没有矛盾也没有反对，但某句话一旦为真，另一句也必然为真（“乙通过了”⇒“甲没通过”）；或者两句话其实是同一个意思（一句条件句和它的逆否句，“除非”改写的选言句），必定同真同假；或者选项本身就是一种完整情况（“入选的两人是”）。
- **最快解法**：在“只有一真”的限定下，能推出别的句子的“强句”必假。2023GD-63 中，“乙通过”一旦为真，三句全真，所以乙没通过。2022GD-61 中，“都获奖”⇒“播种获奖”，所以“都获奖”为假，再分两种情况。等价的两句同真同假：只有一真时二者必假，只有两真时分“同真、其余全假”和“同假、其余恰两真”两种情况。选项是完整情况时，直接代入数真话。
- **通法**：列出所有情况（两个对象 4 种，三个对象 8 种）。
- **陷阱与干扰项**：只找到一种满足条件的情况就作答（问“必然”时要穷尽所有情况）；问“必然错误”时把“可能错误”的项也选了。
- **真题**：2023GD-63、2022GD-61。
- **趋势**：**广东两次都考这一型**。题库缺“补充条件型”（补哪一句使限定成立）和“真话数量待定型”（最多几句为真），已补进第 36 天；“等价（逆否互推）两句同真同假”也是题库缺，补进第 27 天。

### 考法六：嵌套与元陈述（某人说的是假话、说没说真假）

- **识别信号**：话的内容是别人的话的真假（“他二位所言只有一个可信”“乙在说谎”），或是“这几句中恰有几句为真”，或是“被告知了某人说没说真话”。
- **最快解法**：把嵌套句换成它所指那句的否定或肯定；链式指控从最后一句（整体判断）入手；自我指涉计数题先确定“至多一句真”，再排除“全假”；元信息题看“告诉哪种结果时才能唯一确定”（2020SZS-80）。
- **通法**：设各句真值，解方程组（不动点）。
- **陷阱与干扰项**：把“他二位所言只有一个可信”的真假和门的位置混在一起，误选“无法确定”（2020SZS-67 的易错项 D）；元信息题按官方解析那样用选项来排除假设，越做越乱（见第七节问题清单）。
- **真题**：2020SZS-67、2020SZS-80。
- **趋势**：主要出在深圳思维能力卷，国考、省考偶尔出现。改编以 1—2 级的“链式指控”“自我指涉计数”为主，元信息题只放在第 36 天。

### 考法七：一人多句与身份型（半真半假、诚实/说谎/随机）——题库缺

- **识别信号**：每人说两句，“每人恰有一句为真”“一人全对、一人全错、一人半对”；人分诚实者、说谎者（有时还有随意者），问身份或问事实。
- **最快解法**：一人多句时，找两人都说过的同一句话（如“是甲区”），假设它为真，看会不会冲突；身份型先看自指句（说谎者不可能说“我是说谎者”“我们中至少一人说谎”）。
- **通法**：按身份组合穷举（2 人 4 种，3 人 8 种，诚实／说谎／随意三人为 6 种）。
- **陷阱与干扰项**：把“随意者”当成“说谎者”；忘了身份句也可以是真话。
- **真题**：无（题库缺）。
- **趋势**：行测里的常见老题型，广东 2021 县级卷等后补卷中可能出现。第 14、27、36 天各安排 3 道，由易到难。

### 考法八：日常结论·科普与研究材料（同义替换、机制链）

- **识别信号**：实验、观测、生物机制、对照组，问“由此可以推出”。
- **最快解法**：抓关键句（“研究发现”“因此”“但是”后面那句），正确项通常是它的同义替换（2025SD-98 B）或对机制的概括（2022ZJA-105 B）；遇到对照实验先看组间比较（2022SC2-80 A）。
- **通法**：四个选项逐一回原文找依据。
- **陷阱与干扰项**：偷换主体（2024HB-108 A）、扩大范围（2023HB-102 B）、绝对化（2025SD-98 C、D）、应用推断（2024HB-108 D）、时间错置（2022HB-107 C）。
- **真题**：2025SD-98、2022SC2-80、2022HB-107、2025HB-108、2022ZJA-105、2023HB-102、2024HB-108。
- **趋势**：河北连续四年考（2022—2025），也是本模块归纳部分的主体。改编加入“三组对照得‘并非任何…都’”“机制链”“与原因解释嵌套”，情境用设施农业、湾区生态、健康科普等。

### 考法九：日常结论·社科经济与政策材料（主体范围、措施、信息串联）

- **识别信号**：社会调查、经济指标、政策效果、国际关系；常有“为了…”“此后…”“与…负相关”“同步”。
- **最快解法**：信息串联（A与B负相关、B与C同步⇒C走高则A承压，2022SD-74）；措施类结论用“有助于”收着说（2020HB-108 A）；时间先后不当因果（2024SD-99）。
- **通法**：画出变量关系链，逐项对照。
- **陷阱与干扰项**：比较对象不当（2024SD-99 C）；把特定群体扩大到全体；把相关说成因果，或因果倒置；同期另一变化不能算作政策效果。
- **真题**：2024SD-99、2020HB-108、2022SD-74。
- **趋势**：山东偏爱。改编用政务情境（12345 热线、错峰配送、助餐服务、跨境通关），和广东论证题的语境最接近。

### 考法十：关联词与论述结构（条件、并列、递进、唯一）

- **识别信号**：材料不是形式化条件句，但含“离不开”“缺一不可”“不应忽视”“关键在于…否则…”“不仅…也／更要”“唯一”“很大程度上”。
- **最快解法**：把口语化的关联词翻成必要、充分、并列或递进关系，选项只认关系不变的那一项（2020HB-103 B：构建文化链→不应忽视书店）。
- **通法**：标出关联词，逐项核对关系。
- **陷阱与干扰项**：必要改充分（2020HB-103 A）、并列改因果（2020HB-103 C）、“很大程度上”改成“完全”、“唯一”的作用范围被扩大（2023GK-110）、“大多数”换位（“下滑的大多只靠线下”≠“只靠线下的都下滑”）。
- **真题**：2020HB-103。
- **趋势**：题库只有 1 道，但它与翻译推理直接相通，第 14、36 天各安排一组。

### 考法十一：数量与比例型结论（单价×数量、占比、平均数）——题库少

- **识别信号**：材料给出单价、数量、比重、增长率、平均分，问“可以推出”。
- **最快解法**：只算判断方向所需的那一步。总量＝单价×数量（2020SC1206-84）；部分量＝比重×总量（比重升 10 个百分点、总量降 10%，0.5×0.9 与 0.4 比大小）；总平均介于各组平均之间、偏向人多的一组；混合增速居中；“过半＋过半”必有重叠。
- **通法**：赋值（总量设为 100 或 1）列式。
- **陷阱与干扰项**：人次≠人数、车次≠车辆数、比重≠数量、百分点≠百分比、平均≠个体、增长率直接相加（8%＋3%）、简单平均代替加权平均。
- **真题**：2020SC1206-84。
- **趋势**：国考、省考的结论型题越来越多地带数据。题库只有 1 道，四天都安排，另与考法八、九、M09、M11、M12 做跨模块组合。

### 考法十二：规则·定义·公式适用型（套规则、代特值）——题库少

- **识别信号**：材料给出公式（区分度 D=P_H−P_L、BMI、标准分）、分级规则（召回、信用、阶梯水价）或定义，问“可以推出”。
- **最快解法**：代特值验证（难度为 1 时 D=0；身高 1.6 米、体重 60 千克时 BMI≈23.4），反例一出现就排除；分类规则先确定对象“一定不属于”哪一类。
- **通法**：逐项按规则计算。
- **陷阱与干扰项**：线性误用（用水量 2 倍≠水费 2 倍）；“符合条件”与“已经持有”混为一谈；抽检不合格率当成整批不合格率；公式中的分母弄错。
- **真题**：2024JSA-102。
- **趋势**：江苏 2024 年出现，广东的综合推理和翻译推理也常给“规则”。第 27、36 天各安排一组。

### 考法十三：反向与弱化设问（不能推出、最能支持、可能/不可能为真）——题库少

- **识别信号**：设问是“不能推出”“最能支持的论断／建议”“最不能支持”“以下哪项不可能为真”“最可能推出”。
- **最快解法**：选非题逐项找依据，找到一项既无依据又不被题干蕴含的就停（2023GK-110 C）；“最能支持”可以接受温和的趋势推断，但不能接受绝对化或无数据的比较（2020SZS-75 C 对 D）；“不可能为真”用极端构造反证。
- **通法**：逐项判断。
- **陷阱与干扰项**：把“最能支持”当成“必然推出”而不敢选带趋势的项；选非题选了一个其实能推出的“表述生硬”项。
- **真题**：2023GK-110、2020SZS-75。
- **趋势**：广东偏爱反向设问（原因解释、加强、削弱中常见“最不能”）。题库里归纳类的反向设问只有 2 道，所以除了第 27、36 天的专组，还在第 7、14 天的考法八、九组里放了 4 道“不能推出”。

## 四、改编方向（巩固 / 深化 / 拓展）

> 定义：**巩固**＝同一考法换问法，或已知与所求互换（只有一真↔只有一假、正推↔反推、问结果↔问谁说真话），不只是换情境；**深化**＝多一步转化、关系更隐蔽、两个考法嵌套、需要分类讨论，或追问“可能／一定／无法确定”；**拓展**＝新情境新结构（政务、产业、大湾区、民生）、跨模块组合（计数、比例、平均数、构造），或题库没有但行测常见的变形。
> 下表“骨架”中凡已排进第六节的，都已在 `bp_L02_work/ideas_v2.py` 里验算过。所有改编都**不沿用种子真题的原句子组合和数据**（考生通常刚做完那道真题）：同构只保留“考法”，句子、关系对、结论位置都换掉。

| 一 | ① 真假限定互换：只有一真→只有一假，其余由“全假”变“全真”（百千万工程三项目）；② 问法换成“谁猜对＋结果”组合项，或“一定为假” | ① 5句只有一真，要连写三次否定（“甲入选或乙落选”为假→甲落选且乙入选）；② 问“真假无法确定” | ① 判完真假后问“有几人通过”；② 名次情境的补集矛盾（“一等奖是丙”与“一等奖在甲乙丁戊中”） |
