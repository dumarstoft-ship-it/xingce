# 广东省考 42 天习题本 —— 题型分类标准

## A. 数学运算模块（代码 M01–M14，每题只归一个主模块）

| 代码 | 模块 | 包含 | 归类要点 |
|---|---|---|---|
| M01 | 基础应用：和差倍比与比例 | 和差倍比、比例分配、百分数/增长率类应用、赋值比例、普通方程（一元/多元，有唯一解）、年龄问题以外的"求某个量" | 没有工程/行程/利润/浓度等明显特征、靠列方程或比例即可解的题 |
| M02 | 不定方程与数字特性 | 不定方程（组）、整数解讨论、奇偶性、整除/倍数特性代入、尾数法、多解取唯一 | 方程个数少于未知数个数，或核心是用整数/奇偶/倍数特性筛选 |
| M03 | 工程问题 | 给定时间型、效率比型、给具体单位型、交替合作、多人合作中途变化、牛吃草/资源消耗、蓄水排水 | 出现"完成/效率/合作/单独做/工作量"或可抽象为"总量=效率×时间"的消耗问题 |
| M04 | 行程问题 | 相遇追及、多次相遇、往返、环形、流水行船、比例行程、平均速度、扶梯、火车过桥、发车间隔 | 速度×时间=路程 |
| M05 | 经济利润 | 成本/售价/利润/利润率、打折促销、分段计费（水电费、个税、话费）、利润最值（二次函数/均值）、方案比较 | 价格与利润为核心 |
| M06 | 排列组合 | 分类分步、捆绑、插空、隔板、错位排列、环形排列、分组分配、相同元素分配、枚举计数 | 问"多少种" |
| M07 | 概率问题 | 古典概率、独立事件、对立事件、条件概率/贝叶斯、多次独立重复、加权平均型概率、期望 | 问"概率/可能性" |
| M08 | 几何问题 | 平面几何（面积、周长、相似、勾股、三角形/圆）、立体几何（表面积、体积、切割、展开、最短路径）、几何计数、几何最值、解析几何情境 | 以图形度量为核心 |
| M09 | 最值问题 | 最不利原则（抽屉原理）、和定最值（构造数列）、多集合反向构造（"至少…都…"）、一般不等式/函数最值（非利润） | 问"至少/最多/最少"，核心是构造或最不利 |
| M10 | 统筹优化与线性规划 | 时间统筹（排队、烙饼、过河）、资源/费用最优（运输、调配、选址、货物集中）、线性规划（多约束求最大/最小）、方案最优、存储/等待成本最小 | 多约束下找最优方案 |
| M11 | 容斥问题 | 两集合、三集合标准型/非标准型、画图法、容斥极值 | 集合重叠计数 |
| M12 | 溶液混合与平均数 | 浓度、混合配比、多次蒸发/稀释、加权平均、十字交叉、平均数变化 | 浓度或平均数为核心 |
| M13 | 周期、日期与杂题 | 周期循环、星期日期、年龄问题、植树/方阵、钟表、比赛场次、空瓶换酒、页码、鸡兔同笼等 | 不属于以上的经典杂题 |
| M14 | 数论与计算 | 约数倍数（最大公约数/最小公倍数）、余数与同余、数列与求和、多位数、新定义运算、递推、计算技巧 | 纯数学关系，弱情境 |

边界规则：
- 概率题即使要用排列组合计数，也归 M07。
- 利润最值归 M05；线性规划类的利润/费用最优（多约束）归 M10。
- "至少/最多"如果是线性约束优化归 M10；如果是抽屉/构造归 M09。
- 牛吃草、资源消耗（如蓄电池供设备运行）归 M03。
- 年龄问题归 M13。
- 题目有图但核心是工程/行程等，按核心归类；只有图形度量是核心才归 M08。

## B. 逻辑判断模块（代码 L01–L07）+ 综合推理（C01–C05）

| 代码 | 模块 | 设问特征 |
|---|---|---|
| L01 | 翻译推理 | 题干含条件关系（如果…那么、只有…才、除非、所有/有的、或者/并且），问"可以推出""补充哪项可以得出""必然为真/假"；含对当关系、负命题 |
| L02 | 真假推理与归纳推理 | ① 真假话：几个人说话、只有一真/一假等；② 归纳推理/日常结论：根据一段非形式化材料问"可以推出/不能推出/最能概括" |
| L03 | 加强论证 | 支持、加强、证明、最不能支持（"最不能支持"也归这里） |
| L04 | 削弱论证 | 削弱、质疑、反驳、驳斥、最不能削弱/质疑（也归这里） |
| L05 | 前提假设 | 需要补充的前提、暗含前提、假设、"使上述推论成立" |
| L06 | 原因解释 | 解释现象/矛盾/差异、最不能解释 |
| L07 | 结构相似与论证评价 | 逻辑结构最相似、所犯逻辑错误最相似、论证方式、对论证的评价、作用、焦点 |
| C01 | 综合推理·排序与位置 | 直线/环形座位、排队、名次、楼层、时间先后、相邻关系 |
| C02 | 综合推理·匹配对应 | 人—职业—地点等二维/三维对应 |
| C03 | 综合推理·分组与选择 | 选人、组队、每人会/选几种、分配到组、取舍组合 |
| C04 | 综合推理·数量与大小比较 | 得分/数量大小比较、和差关系推排序、数量推理、计算型推理 |
| C05 | 综合推理·混合与一拖n | 条件+真假混合、多维综合、一个题干多问 |

边界规则：
- 综合推理（C）= 粉笔所说的"组合排列/分析推理"：多个对象按若干条件做排序、匹配、分组、数量推算，通常用排除法/代入法/列表法解。广东 2026 第 62、63 题、2024 第 55、58 题是典型。
- 题干以条件句为主、对象少、考推理规则的归 L01，不归 C。
- 真假话题若核心在找矛盾/反对关系归 L02；若需要先判真假再做排序匹配归 C05。

## C. 其他判断推理题型（不进习题本，但分类时请识别出来）
- 图推、定义判断、类比推理：如果混进了逻辑判断批次，标记 kind=图推/定义/类比。

## D. 难度
1 = 基础（套路直接、一步到位，≤60 秒）；2 = 中等（需两三步或一个技巧，60–120 秒）；3 = 难（多步/综合/计算量大，>120 秒，考场可放弃）。
